## 1. Architectural Taxonomy

1. **Frontier LLM Providers & Reasoning Engines**: OpenAI, Anthropic (Claude / Claude Code), Google Gemini, DeepSeek, Hugging Face
2. **Agent Orchestration & Multi-Agent Swarm Frameworks**: CrewAI, AutoGen (Microsoft), LangChain / LangGraph
3. **RAG Frameworks & Vector Databases**: LlamaIndex, ChromaDB, Pinecone, Weaviate, Qdrant, Milvus
4. **High-Throughput Model Serving & Local Inference**: vLLM, Ollama, ONNX Runtime, TensorRT (NVIDIA)
5. **Foundational Deep Learning & Classical ML**: PyTorch, TensorFlow, Keras, scikit-learn
6. **Distributed Compute, MLOps & Telemetry**: Ray (Anyscale), MLflow, Weights & Biases (W&B)
7. **Protocols & Algorithmic Compilers**: MCP (Model Context Protocol), DSPy (Stanford NLP)
