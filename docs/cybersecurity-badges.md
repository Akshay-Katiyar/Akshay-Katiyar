## 5. Critical Guidelines: Truthful Representation

1. **Only Display Verifiable Capabilities**:
   - If showcasing tools like SonarQube, Snyk, Dependabot, or GPG, ensure they reflect actual repos with CI/CD checks or signed commits.
2. **Never Claim Fake Certifications**:
   - Do not display OSCP, CISSP, or CEH unless backed by public Credly/Accredible verification links.
3. **Clarify Security Roles**:
   - Distinguish application security integration (configuring SAST/DAST/linters) from dedicated offensive red-teaming or penetration testing.
